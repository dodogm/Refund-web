# 💻 Refund Web
### Frontend em React + TypeScript para gerenciamento de reembolsos

---

## 📖 Sobre o Projeto
O **Refund Web** é a interface frontend desenvolvida em **React + TypeScript** que consome a **Refund API**.  
O objetivo é fornecer uma aplicação visual para que usuários possam solicitar, acompanhar e gerenciar reembolsos de forma prática.

## ⚙️ Guia de Instalação e Execução

### 📌 Pré-requisitos
- **Node.js** instalado (versão 18 ou superior recomendada)
- **npm** ou **yarn**

### 🚀 Passo a passo
```bash
# Clonar o repositório
git clone https://github.com/dodogm/Refund-web.git

# Entrar na pasta do projeto
cd Refund-web

# Instalar dependências
npm install

# Rodar a aplicação em modo desenvolvimento
npm run dev
