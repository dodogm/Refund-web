# 💸 Refund API
### API em Node.js para gerenciamento de reembolsos

---

## 📖 Sobre o Projeto
O **Refund API** é uma aplicação backend desenvolvida em **Node.js** que fornece endpoints para gerenciar solicitações de reembolso.  
O objetivo é praticar conceitos de APIs REST, manipulação de dados e integração com sistemas externos.

### 🛠️ Tecnologias Utilizadas
- Node.js
- Express.js
- JavaScript
- Git & GitHub
- Bcrypt
- Cors
- Jsonwebtoken
- Multer
- Zod

---

## ⚙️ Guia de Instalação e Execução

### 📌 Pré-requisitos
- **Node.js** instalado (versão 18 ou superior recomendada)
- **npm** ou **yarn**

### 🚀 Passo a passo
```bash
# Clonar o repositório
git clone https://github.com/dodogm/Refund-api.git

# Entrar na pasta do projeto
cd Refund-api

# Instalar dependências
npm install


Frontend (React/HTML) → Backend (Node.js/Express) → Banco de Dados (SQLite)

# Rodar a aplicação
npm start
